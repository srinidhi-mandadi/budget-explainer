# 💰 AI Budget Explainer

AI Budget Explainer is an AI-powered application that helps users understand and analyze their budget in a simple and easy-to-understand way.

The application is built using **Python, Streamlit, and Ollama** to provide interactive budget analysis and AI-generated explanations.

---

## 🚀 Features

- 📊 Analyze budget information
- 🤖 AI-powered budget explanations
- 💡 Get simple insights from financial data
- 📈 Interactive Streamlit interface
- 🧮 Budget and expense analysis
- 🔐 Support for environment variables
- ⚡ Fast and easy-to-use interface

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Ollama**
- **Pandas**
- **HTML/CSS**
- **Git & GitHub**
